## 动作游戏

- **[Hypersomnia](https://hypersomnia.io)** - 节奏极快、手感凌厉的俯视角竞技射击游戏，自带像素怀旧味与内置地图编辑器。 [[source]](https://github.com/TeamHypersomnia/Hypersomnia)

- **[Trick or Take](https://trickortake.com)** - 节奏紧凑的 60 秒万圣节多人糖果大劫案休闲竞技网页游戏，支持实时空间语音，浏览器即开即玩。 [[source]](https://github.com/zicojiao/trick-or-take)

## 冒险游戏

- **[Dead Ascend](https://blackgrain.dk/games/deadascend)** - 一款僵尸题材冒险逃生室游戏，反转不断。 [[source]](https://github.com/larpon/DeadAscend)

- **[Endless Sky](https://endless-sky.github.io)** - 太空探索、贸易与战斗游戏。 [[source]](https://github.com/endless-sky/endless-sky)

- **[Pioneer](https://pioneerspacesim.net)** - 以 33 世纪初我们的银河系为舞台的太空冒险游戏。 [[source]](https://github.com/pioneerspacesim/pioneer)

- **[ScummVM](https://www.scummvm.org)** - 让你在现代设备上运行一批经典图形冒险与角色扮演游戏的程序。 [[source]](https://github.com/scummvm/scummvm)

- **[The Legend of Zelda: Twilight Princess](https://zsrtp.link)** - 逆向工程项目：将 *[Twilight Princess](https://en.wikipedia.org/wiki/The_Legend_of_Zelda:_Twilight_Princess)* 反编译为人类可读、可修改的源码。 [[source]](https://github.com/zeldaret/tp)

- **Zelda 3** - 逆向工程复刻 *[The Legend of Zelda: A Link to the Past](https://en.wikipedia.org/wiki/The_Legend_of_Zelda:_A_Link_to_the_Past)*。 [[source]](https://github.com/snesrev/zelda3)

## 城市建造游戏

- **[Akhenaten](https://dalerank.itch.io/akhenaten)** - 策略城市建造游戏，基于 *[Pharaoh + Cleopatra](https://en.wikipedia.org/wiki/Pharaoh_(video_game))*（法老王 + 埃及艳后）的素材与玩法机制，玩家扮演古埃及文明的统治者和市长。 [[source]](https://github.com/dalerank/Akhenaten)

- **[Citybound](https://aeplay.org/citybound)** - 城市建造游戏：用微观模型生动模拟一座城市的有机体——它诞生于数百万个体之间的相互作用。 [[source]](https://github.com/citybound/citybound)

- **[Cytopia](https://cytopia.itch.io/cytopia)** - 免费开源的复古像素风城市建造游戏。 [[source]](https://github.com/CytopiaTeam/Cytopia)

- **Egregoria** - 独立城市建造游戏，灵感主要来自 *[Cities: Skylines](https://en.wikipedia.org/wiki/Cities:_Skylines)*（城市：天际线）。 [[source]](https://github.com/Uriopass/Egregoria)

- **[IsoCity](https://iso-city.com)** - 用 NextJS、TypeScript 与 TailwindCSS 构建的等距视角城市建造模拟游戏。 [[source]](https://github.com/amilich/isometric-city)

- **Julius** - *[Caesar III](https://en.wikipedia.org/wiki/Caesar_III)*（凯撒大帝 3）的开源重实现。 [[source]](https://github.com/bvschaik/julius)

- **[micropolisJS](http://www.graememcc.co.uk/micropolisJS)** - 手工移植成 Javascript 的开源城市模拟器 *[Micropolis](https://mvolution.itch.io/micropolis)*。 [[source]](https://github.com/graememcc/micropolisJS)

- **[Unknown Horizons](https://unknown-horizons.org)** - 强调经济与城市建设的 2D 实时战略模拟游戏。

  - **原版：** [[source]](https://github.com/unknown-horizons/unknown-horizons) **引擎：[FIFE](https://www.fifengine.net/)** [[source]](https://github.com/fifengine/fifengine)
